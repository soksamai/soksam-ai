# Security Policy

Security and privacy reports for **SokSam AI** should not be published in public GitHub issues.

Please do **not** post:

- passwords, API keys, access tokens or credentials;
- private conversations or personal user data;
- authentication details;
- private infrastructure information;
- exploit instructions or unpatched vulnerability details.

Use the official security page for current reporting guidance:

**https://soksam.pp.ua/security**

Public GitHub Issues are appropriate only for ordinary product bugs and documentation problems that do not expose sensitive information.
