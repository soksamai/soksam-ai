# SokSam AI public roadmap

SokSam AI is currently in a deep public demo and rapid-development stage.

The product is usable today, while features, limits, model availability, interfaces and pricing can continue to change quickly.

## Current direction

Public development is focused on:

- improving adaptive model routing and reliability;
- expanding multimodal workflows across files, images and voice;
- improving Telegram and browser access;
- expanding SokSam AI Studio and its OpenAI-compatible developer workflow;
- improving account, authentication and security flows;
- refining multilingual behavior and usability;
- publishing clearer product documentation and public status information.

The project is expected to receive meaningful updates approximately every week during this stage, although exact release timing is not guaranteed.

Paid subscriptions are not implemented yet; Free is currently the available subscription tier.

Future roadmap details may change as SokSam AI evolves.
