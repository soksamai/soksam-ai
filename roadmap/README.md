# SokSam AI — Public roadmap

SokSam AI is a usable **deep public demo** with active ongoing development. This page distinguishes **features available now** from **areas of future improvement**; it does not promise specific ship dates.

## Available now

- Chat with four public tiers, a multilingual interface, file and image workflows, web research and supported document creation.
- **SokSam Agent** for signed-in users: multi-file project generation and revisions, progress, history, saved versions and supported previews.
- **My Files** with personal folders, viewers, file versions, basic **2 GB** space and options for additional space through virtual credits.
- **Studio** on desktop with personal API keys, eight developer model variants, usage visibility and shared virtual credit activity.
- Virtual starter and recurring credit opportunities, plus an optional verified one-time Telegram reward.
- Browser and conversational Telegram access, each with its own supported workflows.

## Areas being refined

- Reliability of longer Agent jobs, supported previews, task history and recovery after interruptions.
- Smooth file uploading, document creation, editing and result retrieval.
- Clearer usage, credit activity and developer API onboarding.
- Search/source workflows and multilingual documentation.
- Accessibility, navigation, user experience, authentication and security.
- Further supported integrations and model availability as the product evolves.

These are **directions**, not commitments to a particular feature set or deadline. A previously introduced feature should not be mistaken for something still unreleased.

## Plans and updates

The only available subscription plan is currently **Free**. Paid subscriptions, card payments and credit purchases are **not implemented**.

For actual release dates, consult the [official changelog](https://soksam.pp.ua/changelog). No weekly cadence is guaranteed. Demo interfaces, limits and virtual credit conditions may change.
