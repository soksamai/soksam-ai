# Contributing to SokSam AI

Thank you for helping improve the public SokSam AI experience.

This repository is primarily for **public product information, documentation and issue reporting**. The proprietary production application source code is not published here.

Useful public contributions include:

- documentation corrections;
- broken-link reports;
- reproducible public product bugs;
- accessibility feedback;
- clear feature suggestions;
- improvements to public examples and explanations.

Please do not submit private conversations, personal user data, credentials, API keys, tokens, private infrastructure details or security vulnerabilities in public issues or pull requests.

For security matters, follow [`SECURITY.md`](SECURITY.md).
