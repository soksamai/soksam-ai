## One workspace, four ways to work

| Start here | Best for | Where it leads |
|---|---|---|
| **Chat** | Questions, research, writing, images and shorter tasks | Answers and downloadable results |
| **Agent** | Websites, games, bots and other multi-file projects | A project folder, progress, versions and supported previews |
| **My Files** | Organizing sources and finished work | Folders, previews, edits, history and downloads |
| **Studio** | API connections, model choices and credit activity | Personal API keys and a shared virtual credit balance |

Use **Chat** to explore an idea, **Agent** to build on it, **My Files** to keep the work, and **Studio** to manage developer access and credits. These are complementary workflows, not four different subscriptions.

## Build with SokSam Agent

**SokSam Agent is available to signed-in users now.** Open the web app and choose **Agent** in the left menu. It runs project tasks in an isolated environment on SokSam servers, not on your own computer.

Describe a goal such as **“Build a small café website,” “Create a browser game,” “Improve my existing project,”** or **“Make a tool for processing spreadsheets.”**

- Work with multiple files in a dedicated project folder and conversation.
- Upload starting materials, including drag-and-drop files, and continue existing projects.
- Follow progress and action history, then inspect saved versions and changes.
- Preview supported websites and games, and find project results in **My Files**.
- Choose SuperFlash, Standard, Nova or Max and see the credit balance and work cost.

Agent plans, edits, runs available checks and attempts fixes. Supported previews and checks depend on the project; results are not guaranteed error-free or automatically published to external hosting.

## Chat, research and create

SokSam offers **30 interface languages**, four public chat tiers (**SuperFlash, Standard, Nova, Max**) and an adaptive backend pool of roughly **50 eligible models**. A tier is a stable product choice; the underlying eligible model can vary with availability and workload.

In the browser, you can:

- Ask questions and **search the web with sources**, or investigate a topic more deeply by comparing several sources.
- Read supported documents and create or edit **Word/PDF documents**, **Excel/CSV tables**, calculations, charts and **PowerPoint presentations**.
- Understand images and generate new images; use supported browser voice input and multilingual speech generation.
- Organize longer conversations using chat projects, branches, bookmarks and explicit memory tools.
- Follow visible task stages when SokSam searches, reads, processes files or prepares an output.

Availability can differ by task, model and interface; verify important research findings and generated materials.

**Guides:** [Search & research](docs/SEARCH-AND-RESEARCH.md) · [Create & export](docs/CREATE-AND-EXPORT.md) · [Feature guide](docs/FEATURES.md)

## Keep everything in My Files

**My Files** is your personal workspace for source materials and finished results. Create folders; upload, search, rename, move, copy and download files; restore items from the trash; and review saved versions. Supported documents, images and media have viewers, while text and code files can be edited. ZIP workflows are available within supported limits.

Generated documents, images and Agent projects can be kept in their respective folders. The included storage space is **2 GB**; additional space is available through Studio virtual credits. File security checks have visible statuses, but no automated check is an absolute guarantee.

[Learn about My Files](docs/MY-FILES.md) · [File support and chat attachment limits](docs/FILE-SUPPORT.md)

## Studio and virtual credits

**[SokSam AI Studio](https://soksam.pp.ua/soksam/studio)** is the **desktop-browser** developer area. Create personal API keys, find the current OpenAI-compatible endpoint details and model IDs, select from **eight Studio variants**, and review usage plus credit activity. Format compatibility does not imply an official partnership or guaranteed support for every third-party tool.

One **Studio credit balance** (shown in virtual USD, not withdrawable money) covers **Agent work**, **Studio API requests** and **extra My Files storage**. **Ordinary chat does not consume Studio credits** and still has its own usage limits.

| Virtual credit opportunity | How it works |
|---|---|
| **$5 once** | Starting balance for an account |
| **$1 per day** | Claimed by opening Studio, once per UTC day (new day at 00:00 UTC) |
| **$10 once** | Optional Telegram reward with verified channel subscription and 10 qualifying unique bot messages after joining |

**Free is the only available subscription plan.** Paid subscriptions, card payments and purchased top-ups are not available. Credit terms above were checked **14 November 2026** and can change during the demo: consult live Studio for current terms.

[Complete credit rules](docs/CREDITS.md) · [Studio guide](docs/STUDIO.md)

## Choose a workflow

- **Research an issue:** ask Chat to find sources, compare them and cite what it uses.
- **Prepare a report:** give Chat source material and request a document, spreadsheet or presentation.
- **Build something:** describe a site or game in Agent, then inspect the project and files.
- **Connect software:** create an API key in desktop Studio and configure a compatible application.

For a simpler conversation in Telegram, use [@vibescripthelper_bot](https://t.me/vibescripthelper_bot). The [official news channel](https://t.me/vibescriptaibest) shares updates. Telegram does not automatically include every browser, Agent or Studio capability.
