# SokSam Agent — build projects from an idea

**Status: available to signed-in SokSam AI web users.** Open [SokSam AI](https://soksam.pp.ua/soksam/chat) and select **Agent** from the left navigation. A separate direct Agent URL is not documented here because it has not been verified.

## When to use Agent

Use Chat for a question, a piece of research, a document or a small task. Use **Agent** when the work involves **a project made of several files**, such as a website, a browser game, an application, a bot or a small automation tool.

Try asking:

- “Build a website for a small café.”
- “Create a browser game with a score screen.”
- “Continue this project using the files I uploaded.”
- “Make a tool that transforms a table into a report.”

## From instruction to project

1. Sign in and open **Agent** from the left menu.
2. Describe your goal, or continue an existing project.
3. Upload source files when helpful, including by dragging and dropping.
4. Select a SokSam level: **SuperFlash, Standard, Nova or Max**.
5. Follow the displayed progress as Agent plans, creates or modifies files, runs available checks and attempts corrections.
6. Review the result, saved versions and history; preview supported websites or games.
7. Find the resulting files in **My Files**, and continue improving the project in its own conversation.

Each Agent project has its own folder and discussion. Changes can span multiple files, and task history helps you understand what has happened. The project is processed in an isolated environment on SokSam's servers.

## Credits and interruptions

Agent uses the shared **Studio virtual credit** balance, including work spent on planning and final checks. You can see your available balance and task cost in the Agent and Studio interfaces. If the balance cannot cover the next step, Agent pauses; check Studio for available ways to receive virtual credits.

Regular Chat does **not** deduct Studio credits. The current subscription plan is **Free**. [See credit rules](CREDITS.md).

## What to expect

Agent can help build and revise a working project, but **not every technology stack, check or preview is supported**. A preview is offered for supported project types, not every program. Review and test important outputs yourself. Agent does **not** automatically deploy projects to an external host and should not be understood as having unrestricted access to your computer, GitHub account or server secrets.
