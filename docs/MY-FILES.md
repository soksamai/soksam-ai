# My Files — your SokSam workspace

**My Files** is personal storage connected to SokSam Chat and Agent. It brings source materials and created results together so they can be found, reviewed and reused later.

## Organize and retrieve

- Create folders and upload files.
- Rename, move, copy, search and download files.
- Find recently used materials.
- Recover supported deleted items from the trash.
- Inspect saved file versions and change history.
- Work with supported ZIP archives within current limits.

## Preview and edit

My Files includes PDF and image viewers, playback for supported media, and an editor for text and code files. Available previews and editing depend on file type.

Generated documents, images and completed project materials can be kept in appropriate folders. An Agent project is linked to its **own project folder and work history**, making it easier to continue improving it.

## Space and virtual credits

The included personal storage space is **2 GB**. You can obtain additional space using the shared **Studio virtual credit** balance. View current expansion options and costs in the product; this document intentionally does not publish an unverified price table.

**Important:** total My Files storage, individual storage-file limits and **Chat attachment limits are separate**. The numbers in [FILE-SUPPORT.md](FILE-SUPPORT.md) describe chat-message attachments and should not be interpreted as universal storage limits.

## File checks and care

My Files displays file antivirus-check status. That visibility helps you understand whether a check has completed, but it does **not guarantee absolute file safety**. Keep your own backups of important materials and review generated or downloaded content when appropriate.

## A simple workflow

1. Upload research notes or starter code to My Files.
2. Use Chat to analyze material or Agent to build a project.
3. Open the saved results in My Files.
4. Preview, edit, download or return to an earlier version where supported.
