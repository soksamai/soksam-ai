# SokSam AI virtual credits

**Terms checked: 14 November 2026.** These are demo-stage rules; the live [Studio](https://soksam.pp.ua/soksam/studio) interface is the source for current balance, activity and conditions.

**Studio credit** is a virtual balance displayed in **USD** for use **inside SokSam AI**. It is **not real cash**, cannot be withdrawn or converted into money, and is not a paid subscription.

## What uses the shared balance?

| Uses Studio credits | Does not use Studio credits |
|---|---|
| SokSam Agent work, including planning and final checks | Ordinary SokSam Chat (subject to its own usage limits) |
| Personal Studio API-key requests | Viewing this public documentation |
| Extra space beyond the included My Files storage | |

The balance and its activity are visible through Studio and the Agent interface. If the balance cannot cover Agent's next step, the task pauses.

## Three ways to receive virtual credits

| Credit | Conditions |
|---|---|
| **$5 start** | Granted **once** per account as the initial virtual balance |
| **$1 daily** | Claim by **opening Studio**. At most once per day; each new day begins at **00:00 UTC** |
| **+$10 Telegram bonus** | A **one-time** reward after meeting all verified conditions described below |

The daily amount **does not arrive automatically if you never open Studio**. The balance does **not reset to zero each midnight**. Bonuses add to the existing balance, minus any credits already spent.

## Telegram bonus: all required steps

1. Start the bonus process **from Studio**.
2. Subscribe to the [official Telegram channel @vibescriptaibest](https://t.me/vibescriptaibest).
3. **After subscribing**, send **10 qualifying, unique text messages** to the [official AI bot @vibescripthelper_bot](https://t.me/vibescripthelper_bot).
4. Let SokSam automatically verify the subscription and message conditions.

Simply joining the channel or sending one message is **not enough**. The reward is **one-time** and subject to the current qualification checks shown in Studio.

## Plans, pricing and limits

- **Free** is currently the only available subscription plan.
- Paid plans, credit purchases, card payment and paid top-ups **have not been implemented**.
- Extra My Files space can use virtual credits; this does **not** imply that paid plans exist.
- Exact per-task credit costs and storage expansion options should be checked in the live product. Do not assume a fixed price from this guide.
- API endpoint identifiers and current model options are shown in Studio.
