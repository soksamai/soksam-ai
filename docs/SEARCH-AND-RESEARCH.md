# Search and research with SokSam Chat

Use [SokSam Chat](https://soksam.pp.ua/soksam/chat) to explore questions beyond a single answer.

## Find information with sources

For current topics, Chat can search the web, read supported pages and show sources alongside findings. Ask for the sources behind an answer so you can inspect them yourself.

**Example:** “Compare the main changes to this technology over the past year. Include source links.”

## Explore a topic more deeply

For a broader question, ask for a deeper investigation that draws on several sources, compares evidence and highlights uncertainty or disagreement.

**Example:** “Research three approaches, compare trade-offs and explain which questions still need verification.”

## Work with your own materials

Provide supported files and ask SokSam to summarize, contrast or organize them alongside research. You can ask for a report or table based on the findings.

Search and reading steps may be visible while a task is processed. Source quality and availability vary; generated summaries and citations can still contain errors. Verify consequential facts using original materials.
