# SokSam AI voice generation

SokSam AI includes a text-to-speech / voice-generation function for turning written text into generated spoken audio.

## Current workflow

1. Enable the voice-generation function in SokSam AI.
2. Enter the text you want to turn into speech.
3. Keep the input within the current **500-character maximum**.
4. Submit the request.
5. SokSam returns generated spoken audio.

## Languages

Voice generation supports multiple languages, including **Russian**. The available voices, languages and quality options may expand as the feature evolves.

## Current status

Voice generation is part of the active SokSam AI deep-demo / rapid-development release. The current 500-character limit, supported voices and language coverage can change in future updates.

For the live product, use https://soksam.pp.ua/soksam/chat.
