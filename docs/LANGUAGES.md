## What localization covers

The multilingual product experience includes user-interface text such as navigation, buttons, authentication screens, settings, notifications and other product surfaces. Public product and model documentation also has multilingual coverage where available.

Arabic is presented with right-to-left layout support where applicable.

## AI conversation language

The interface language and the language used in an AI conversation are separate concepts. Users can write to the assistant in languages supported by the active SokSam model workflow even when the interface itself is set to another language.

## Demo-stage note

Localization continues to evolve during the deep public demo. Translation wording, coverage and additional languages can change in future updates.
