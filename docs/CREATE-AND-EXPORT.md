# Create and export materials

SokSam Chat is useful not only for reading uploaded documents but also for preparing **new, downloadable results** from your instructions and sources.

## What you can make

| Result | Example request |
|---|---|
| **Word / PDF** | “Turn these notes into a clear, formatted meeting report.” |
| **Excel / CSV** | “Build a table with calculated totals and a summary.” |
| **Charts and analysis** | “Analyze the dataset and chart the key trend.” |
| **PowerPoint** | “Create a short presentation with an overview and next steps.” |
| **Images** | “Generate a visual to illustrate this idea.” |

Support for specific output types, formatting, editing and preview depends on the task and current product tools. Review documents, formulas and figures before sharing or relying on them.

## Keep your results

Created documents, tables, slides and images can be kept in their corresponding **My Files** folders. Download a finished item or continue working with it. For a multi-file website, game or application, use **[SokSam Agent](AGENT.md)** instead of treating it as a single chat attachment.

You may see task progress as SokSam reads files, performs calculations or creates the result.
