# SokSam AI public model tiers

SokSam AI presents four stable public model tiers. These names describe the user-facing product choices and are intentionally separate from private provider routing.

| Public tier | Intended use |
|---|---|
| **SokSam SuperFlash** | Fast, lightweight and instant answers |
| **SokSam Standard** | Reliable everyday conversations and work |
| **SokSam Nova** | Deeper tasks and more demanding workflows |
| **SokSam Max** | Maximum available public capability |

## Public contract

Users interact with the SokSam tier names above. Internal provider selection, credentials, fallback topology and private infrastructure are not part of the public model contract and are intentionally not published in this repository.

For current product information, see https://soksam.pp.ua/models.
